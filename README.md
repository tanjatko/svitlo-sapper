# Сапер відключень

Гра «Сапер» на основі графіка відключень світла ДТЕК для Київської області на 10.11.2026.

Відключення — це міни. Цифра показує, скільки відключень у сусідніх клітинках (сусідні черги і години). Мета — відкрити всі години, коли світло є. Є три павербанки: кожне відключення, на яке ви натрапили, забирає один.

- Лівий клік — відкрити клітинку
- Правий клік, довге натискання або «Режим прапорця» — поставити прапорець
- «Моя черга» підсвічує рядок вашої черги
