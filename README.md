# Сапер відключень

Гра «Сапер» на основі сьогоднішнього графіка відключень світла ДТЕК для Київської області.

Відключення — це міни. Цифра показує, скільки відключень у сусідніх клітинках (сусідні черги і години). Мета — відкрити всі години, коли світло є. Є три павербанки: кожне відключення, на яке ви натрапили, забирає один.

- Лівий клік — відкрити клітинку
- Правий клік, довге натискання або «Режим прапорця» — поставити прапорець
- «Моя черга» підсвічує рядок вашої черги

Грати: https://tanjatko.github.io/svitlo-sapper/

Графік підтягується щоразу при відкритті гри з відкритого дзеркала даних ДТЕК [Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua). Якщо воно недоступне, гра використовує збережений графік за 10.11.2026.
